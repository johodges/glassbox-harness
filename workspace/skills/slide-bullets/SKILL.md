# Slide bullets, house style

1. Call search_references first, and write the bullets only from the passages it returns.
2. Write at most 4 bullets, each like a headline: 3 to 6 words, no full stop.
3. Each bullet keeps one fact or number from the passages, written as digits with units.

Example from another topic. Not: "The sprinkler activated after about 90 seconds because the ceiling jet reached 68 °C."
But: "Sprinkler activated at 90 s (68 °C)"
